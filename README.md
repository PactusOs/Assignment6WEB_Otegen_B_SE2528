# jQuery Website

**Student:** Beimzhan Otegen  
**Group:** SE-2528

Five simple pages with jQuery selectors, effects, DOM manipulation, animations, and an accordion menu.

## Pages

- `index.html`: Setup, selectors, text, HTML and CSS.
- `effects.html`: Show, hide, toggle, fade and slide.
- `dom.html`: Add or remove list elements, change attributes and show live form input.
- `animations.html`: Basic, sequential and combined animations.
- `project.html`: Accordion menu.

## Run

Open `index.html` in a browser. Use the navigation links to visit each page. Internet access is needed for jQuery and Wikimedia Commons images. Open the browser console with F12 to check the ready message.
